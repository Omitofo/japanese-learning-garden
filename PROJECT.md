# PROJECT SPEC — Japanese Learning Garden

This is the source of truth for the project.

## Added requirement (Romanization)

**Romanization must appear next to ALL Japanese words**, whether written in kanji, hiragana, or katakana.

Whenever Japanese symbols appear, romanization must be provided nearby so the learner can see how it sounds and make the connection between writing and pronunciation.

This rule applies to:

- Core phrases
- Vocabulary items
- Variations
- Explanations
- Tests
- Any other Japanese text in the repository

Example:

> これください。 (kore kudasai)

## Summary of the system

Japanese Learning Garden is an adaptive learning system based on small sprints. Each sprint uses one useful phrase inside a real circumstance to plant or strengthen a seed, extracts only the necessary knowledge from it, and ends by demonstrating a new communicative capability. The repository records how that capability grows, detects weaknesses, and decides what to water next. There is no obligatory calendar and no goal of completing a syllabus: the objective is to continuously increase what the user can communicate, understand, interact with, and repair in Japanese.
