# S007 — Where Is It?

## Seed

ask-where-something-is (L00 / early L03)

## Circumstance

You need to find something (a place, an object, a station, a toilet, a product…) and you want a simple way to ask where it is.

## Communicative objective

Be able to ask where something is in a simple, polite way.

## Core phrase

これはどこですか。 (kore wa doko desu ka)

## Meaning

Where is this? / Where is it?

(When pointing at a map, a picture, or an item you are holding.)

## Breakdown

### Vocabulary

- これ (kore) — this (already known)
- は (wa) — topic particle (already known from S006)
- どこ (doko) — where
- です (desu) — polite copula (already known)
- か (ka) — question particle (already known)

### Structure

これ + は + どこ + です + か。

This reuses almost the entire pattern from S006, only changing 何 (nan) to どこ (doko).

### Grammar / pattern

Same question pattern as これは何ですか:  
[Thing] + は + [Question word] + です + か

### Pronunciation

- どこ (do-ko)

Smooth unit: **kore wa doko desu ka**

### Context

- Useful when pointing at a map, a photo, or an object whose location you need.
- Also the base for later asking about places by name (e.g. toilet, station).
- Extremely common in daily life.

## Variations

Keep them few and useful:

1. これはどこですか。 (kore wa doko desu ka) — where is this? (pointing)
2. それはどこですか。 (sore wa doko desu ka) — where is that?
3. あれはどこですか。 (are wa doko desu ka) — where is that over there?

Later extension (not required now): replace the demonstrative with a place/object name, e.g. トイレはどこですか (toire wa doko desu ka) — Where is the toilet?

## Practice

1. **Observe**  
   Read: これはどこですか。 (kore wa doko desu ka)

2. **Break it**  
   これ … は … どこ … です … か

3. **Pronounce**  
   Say the full phrase several times until smooth.  
   Notice it is almost identical in rhythm to これは何ですか.

4. **Hide**  
   Produce it from the meaning “Where is this?”

5. **Transform**  
   Change the demonstrative:  
   - this → これはどこですか。  
   - that (near you) → それはどこですか。  
   - that (over there) → あれはどこですか。

6. **Contrast with S006**  
   Practice switching:  
   - これは何ですか。 (what is this?)  
   - これはどこですか。 (where is this?)

7. **Situation**  
   You are looking at a map or holding something and need its location.  
   Ask where it is.

8. **Link with repair**  
   If the answer is too fast or unclear → use your existing repair toolkit.

## Proof of capability

Can you:

- Recognize the phrase?
- Say what it means?
- Produce これはどこですか。 without looking?
- Change the demonstrative?
- Switch cleanly between 何 (nan) and どこ (doko)?
- Use it in a simple situation and fall back to repair tools if needed?

## Before

I had no simple way to ask where something was.

## After

I can ask where something is with これはどこですか。 (kore wa doko desu ka) and switch the demonstrative according to distance. I can also contrast it with the “what is it?” pattern.

new → growing (after practice)

- Strengthens the question frame: [X] は [question word] ですか
