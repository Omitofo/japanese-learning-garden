# S005 — Speak More Slowly

## Seed

basic-repair (extension)

## Circumstance

Someone is speaking too fast for you to follow. You already know how to say you don’t understand and how to ask them to repeat. Now you want them to slow down.

## Communicative objective

Be able to politely ask someone to speak more slowly.

## Core phrase

ゆっくり話してください。 (yukkuri hanashite kudasai)

## Meaning

Please speak slowly. / Please talk more slowly.

## Breakdown

### Vocabulary

- ゆっくり (yukkuri) — slowly / unhurriedly
- 話して (hanashite) — speak (te-form of 話す)
- ください (kudasai) — please (already known)

### Structure

ゆっくり + 話して + ください。

This is a common and natural request pattern: [adverb] + [te-form verb] + ください.

### Grammar / pattern (only what is needed)

- 話す (hanasu) = to speak / to talk
- 話して (hanashite) = te-form (used here to make a request with ください)

You only need the ready-made phrase for now. No need to learn full conjugation yet.

### Pronunciation

- ゆっくり (yuk-ku-ri) — the small っ makes a slight pause/gemination
- 話して (ha-na-shi-te)
- ください (ku-da-sa-i)

Smooth unit: **yukkuri hanashite kudasai**

### Context

- Extremely useful when the other person is speaking too fast.
- Polite and clear.
- Works very well after わかりません or もう一度お願いします.

Common useful sequence:
1. すみません、わかりません。
2. ゆっくり話してください。
3. (optional) もう一度お願いします。

## Variations

Keep them few:

1. ゆっくり話してください。 (yukkuri hanashite kudasai) — standard recommended version
2. ゆっくりお願いします。 (yukkuri onegaishimasu) — shorter, also common
3. ゆっくり。 (yukkuri) — very short, usable when the situation is already clear

## Practice

1. **Observe**  
   Read: ゆっくり話してください。 (yukkuri hanashite kudasai)

2. **Break it**  
   ゆっくり … 話して … ください

3. **Pronounce**  
   Pay special attention to the small っ in ゆっくり (yukkuri).  
   Say the full phrase several times until smooth.

4. **Hide**  
   Produce it from the meaning “Please speak slowly.”

5. **Chain with previous seeds**  
   Practice sequences such as:  
   - すみません、わかりません。 → ゆっくり話してください。  
   - すみません、日本語を勉強しています。 → ゆっくり話してください。  
   - Full chain: request → don’t understand → I’m learning → speak slowly → please repeat

6. **Situation**  
   Someone is speaking very fast.  
   Ask them to slow down.

## Proof of capability

Can you:

- Recognize the phrase?
- Say what it means?
- Produce ゆっくり話してください。 without looking?
- Use the shorter versions?
- Insert it naturally into a survival chain?
