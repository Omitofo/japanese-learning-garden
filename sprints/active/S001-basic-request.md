# S001 — Basic Request

## Seed

basic-request

## Circumstance

You are in a shop, café, or any place where you need to get something. You want to ask for an object in the simplest possible way.

## Communicative objective

Be able to ask for an object using a short, natural, reusable structure.

## Core phrase

これください。 (kore kudasai)

## Meaning

This one, please. / I’ll take this. / Give me this, please.

## Breakdown

### Vocabulary

- これ (kore) — this (thing near me)
- ください (kudasai) — please (give me) / please do…

### Structure

[Object] + ください (kudasai)

You point or hold the object (or point to a picture/menu) and say the phrase.

### Grammar / pattern

This is a very common request pattern.  
ください (kudasai) turns a noun into a polite request for that thing.

You do not need a verb here. The structure is complete as is.

### Particles

No particle is required in this short form.  
(これをください (kore o kudasai) is also correct and slightly more explicit, but the short version is extremely common and natural.)

### Pronunciation

- これ (ko-re) — two clear syllables, stress on the first
- ください (ku-da-sa-i) — four syllables, fairly even, slightly falling at the end

Say it as one smooth unit: **kore kudasai**

### Context

- Use when the object is visible or you can point to it.
- Neutral-polite. Safe in shops, restaurants, convenience stores, etc.
- You can use it while pointing at a menu item, a product on a shelf, or something in someone’s hand.

When **not** to use it alone:
- If the other person has no idea what “this” refers to and you cannot point.

## Variations

Keep them few and useful:

1. これください。 (kore kudasai) — this one, please
2. それください。 (sore kudasai) — that one (near you), please
3. あれください。 (are kudasai) — that one over there, please

(You can later replace the demonstrative with a concrete noun, but that is a future extension of this seed.)

## Practice

1. **Observe**  
   Read: これください。 (kore kudasai)  
   Understand the meaning.

2. **Break it**  
   Say slowly: これ (kore) … ください (kudasai)

3. **Pronounce**  
   Say the full phrase several times out loud:  
   これください。 (kore kudasai)

4. **Hide**  
   Cover the Japanese. Look only at the meaning “This one, please” and produce the Japanese.

5. **Transform**  
   Change the demonstrative:  
   - this → これください。 (kore kudasai)  
   - that (near you) → それください。 (sore kudasai)  
   - that (over there) → あれください。 (are kudasai)

6. **Situation**  
   Imagine you are at a convenience store. You point to a bottle of water and say the phrase.

## Proof of capability

Can you:

- Recognize the phrase when you hear/see it?
- Say what it means?
- Produce これください。 (kore kudasai) without looking?
- Change it to それ or あれ?
- Use it in a simple imagined shop situation while pointing?

If yes to most of these, the capability is planted.

## Before

I could not ask for an object in Japanese in a simple, natural way.

## After

I can point to something and say これください。 (kore kudasai) to request it. I can also switch to それ (sore) or あれ (are) when needed.

## Status

growing

## Observations

- First survival seed.
- Extremely high reuse potential.
- Next natural extensions: replace demonstrative with a noun, add quantity, or ask for the price.
