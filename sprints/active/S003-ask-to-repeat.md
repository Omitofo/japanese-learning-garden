# S003 — Ask to Repeat

## Seed

basic-repair (extension)

## Circumstance

You did not understand what someone said. You already know how to say you don’t understand. Now you want them to say it again so you have a second chance.

## Communicative objective

Be able to politely ask someone to repeat what they just said.

## Core phrase

もう一度お願いします。 (mou ichido onegaishimasu)

## Meaning

One more time, please. / Please say it again.

## Breakdown

### Vocabulary

- もう (mou) — again / more
- 一度 (ichido) — one time / once
- お願いします (onegaishimasu) — please (polite request form)

### Structure

もう一度 + お願いします。

This is a ready-made polite request. You do not need to change it for now.

### Grammar / pattern

- 一度 (ichido) = one time
- お願いします (onegaishimasu) is a very common polite way to ask for something (more formal/polite than just ください in many request situations)

You only need the fixed phrase at this stage.

### Pronunciation

- もう (mou) — long “o” sound
- 一度 (i-chi-do)
- お願いします (o-ne-gai-shi-ma-su)

Smooth unit: **mou ichido onegaishimasu**

### Context

- Extremely useful right after わかりません (wakarimasen).
- Polite and natural with strangers, staff, teachers, etc.
- Often the other person will repeat more slowly or more clearly.

Common sequence:
1. すみません、わかりません。 (sumimasen, wakarimasen)
2. もう一度お願いします。 (mou ichido onegaishimasu)

## Variations

Keep them few:

1. もう一度お願いします。 (mou ichido onegaishimasu) — standard polite version (recommended)
2. もう一度ください。 (mou ichido kudasai) — also common and slightly lighter
3. もう一度。 (mou ichido) — very short, usable when the situation is already clear

## Practice

1. **Observe**  
   Read: もう一度お願いします。 (mou ichido onegaishimasu)

2. **Break it**  
   もう (mou) … 一度 (ichido) … お願いします (onegaishimasu)

3. **Pronounce**  
   Say the full phrase several times until it feels smooth.

4. **Hide**  
   Look only at “One more time, please” and produce the Japanese.

5. **Chain with previous seeds**  
   Practice this sequence out loud:  
   - これください。 (kore kudasai)  
   - (imagine a long reply)  
   - すみません、わかりません。 (sumimasen, wakarimasen)  
   - もう一度お願いします。 (mou ichido onegaishimasu)

6. **Situation**  
   Someone just said something you didn’t catch.  
   First signal you don’t understand, then ask them to repeat.

## Proof of capability

Can you:

- Recognize the phrase?
- Say what it means?
- Produce もう一度お願いします。 (mou ichido onegaishimasu) without looking?
- Use it right after わかりません?
- Run the full survival chain (request → don’t understand → please repeat)?

## Before

I could say I didn’t understand, but I had no simple way to ask the person to say it again.

## After

I can politely ask someone to repeat using もう一度お願いします。 (mou ichido onegaishimasu) and combine it with the previous repair phrase.

## Status

new → growing (after practice)

## Observations

- Direct extension of basic-repair.
- Completes a strong survival loop: request → incomprehension → ask for repetition.
- High reuse value in almost any real conversation.
