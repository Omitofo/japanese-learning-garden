# S012 — How Much Is It?

## Seed

ask-price (new)

## Circumstance

You see something you might buy in a shop, market, café, convenience store, or station. You want to know the price before deciding.

## Communicative objective

Be able to ask how much something costs in a simple, polite way.

## Core phrase

これはいくらですか。 (kore wa ikura desu ka)

## Meaning

How much is this? / How much does this cost?

## Breakdown

### Vocabulary

- これ (kore) — this (thing near me)
- は (wa) — topic particle
- いくら (ikura) — how much (price)
- です (desu) — polite copula
- か (ka) — question particle

### Structure

これ + は + いくら + です + か。

This is exactly the same question frame as これは何ですか and これはどこですか. Only the question word changes (何 → どこ → いくら).

### Pronunciation

- いくら (i-ku-ra)

Smooth unit: **kore wa ikura desu ka**

### Context

Extremely useful in shops, markets, cafés, stations, souvenir shops, etc. Polite and clear. One of the highest-value survival questions for buying things.

## Variations

Keep them few:

1. これはいくらですか。 (kore wa ikura desu ka) — this one (near me)
2. それはいくらですか。 (sore wa ikura desu ka) — that one (near you)
3. あれはいくらですか。 (are wa ikura desu ka) — that one over there
4. すみません、これはいくらですか。 (sumimasen, kore wa ikura desu ka) — with polite attention-getter

## Practice

1. **Observe**  
   Read: これはいくらですか。 (kore wa ikura desu ka)

2. **Break it**  
   これ … は … いくら … です … か

3. **Pronounce**  
   Say the full phrase several times until smooth.

4. **Hide**  
   Produce it from the meaning “How much is this?”

5. **Compare with previous patterns**  
   - これは何ですか。 (what is this?)  
   - これはどこですか。 (where is this?)  
   - これはいくらですか。 (how much is this?)

6. **Situation**  
   You are in a shop or café and see something you might buy. Ask the price. Then thank the person.

7. **Full short chain**  
   すみません、これはいくらですか。 → (get answer) → ありがとうございます。

## Proof of capability

Can you:

- Recognize the phrase?
- Say what it means?
- Produce これはいくらですか。 without looking?
- Switch the demonstrative (これ / それ / あれ)?
- Add すみません in front when needed?
- Close with ありがとうございます after receiving the answer?

## Before

I could ask what something is and where it is, but I had no simple way to ask the price.

## After

I can ask how much something costs with これはいくらですか。 (kore wa ikura desu ka) and switch the demonstrative according to distance. I can also chain it with attention and thanks.

## Status

new → growing (after practice)

## Observations

- Perfect reuse of the existing question frame: [X] は [question word] ですか.
- Extremely high real-life value for any buying situation.
- Natural next companion to basic-request and asking for the bill.
- Completes a useful buying loop: ask price → request item → ask for bill → thank.
