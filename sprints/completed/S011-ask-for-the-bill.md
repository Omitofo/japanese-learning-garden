# S011 — Ask for the Bill

## Seed

basic-request (extension with concrete noun)

## Circumstance

You have finished eating or drinking in a café or restaurant. You want to pay and leave. You need a simple, polite way to ask for the bill.

## Communicative objective

Be able to ask for the bill using a concrete noun + ください.

## Core phrase

お会計をください。 (o-kaikei o kudasai)

## Meaning

The bill, please. / Check, please.

## Breakdown

### Vocabulary

- お会計 (o-kaikei) — the bill / the check (polite form; お is almost always used)
- を (o) — object particle
- ください (kudasai) — please (give me)

### Structure

お会計 + を + ください。

Same request frame as 水をください, only the noun changes. The お prefix is standard and expected with this word.

### Pronunciation

- お会計 (o-kai-kei)
- を (o)
- ください (ku-da-sa-i)

Smooth unit: **o-kaikei o kudasai**

### Context

Extremely useful in any café, restaurant, or izakaya. Polite and clear. Closes the transaction loop after ordering (e.g. after asking for water or food).

## Variations

1. お会計をください。 (o-kaikei o kudasai) — standard clear version (recommended)
2. すみません、お会計をください。 (sumimasen, o-kaikei o kudasai) — with polite attention-getter
3. お会計お願いします。 (o-kaikei onegaishimasu) — alternative polite form (also very common)

## Practice summary

Observed, broken down, pronounced, recalled, varied (standard / with sumimasen / with onegaishimasu), used in situation, and chained with attention + thanks.

## Proof of capability (completed)

User demonstrated:

- Correct recognition and meaning
- Clear understanding of the difference between 水 and お会計
- Accurate production of the core phrase
- Correct use of the main variations
- Natural choice of a polite version + attention in situation
- Clean short chain: attention → ask for the bill → thanks

## Before

I could ask for water and for objects by pointing, but I had no simple way to ask for the bill and close a restaurant interaction.

## After

I can ask for the bill with お会計をください。 (o-kaikei o kudasai) or お会計お願いします。 (o-kaikei onegaishimasu) and combine it with attention-getting and thanks.
