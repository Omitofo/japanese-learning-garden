# S001 — Basic Request

## Seed

basic-request

## Circumstance

You are in a shop, café, or any place where you need to get something. You want to ask for an object in the simplest possible way.

## Communicative objective

Be able to ask for an object using a short, natural, reusable structure.

## Core phrase

これください。 (kore kudasai)

## Meaning

This one, please. / I’ll take this. / Give me this, please.

## Breakdown

### Vocabulary

- これ (kore) — this (thing near me)
- ください (kudasai) — please (give me) / please do…

### Structure

[Object] + ください (kudasai)

### Grammar / pattern

ください (kudasai) turns a noun into a polite request for that thing. No verb needed.

### Particles

No particle required in the short form. (これをください is also correct but less common in quick requests.)

### Pronunciation

- これ (ko-re)
- ください (ku-da-sa-i)

Smooth unit: **kore kudasai**

### Context

Neutral-polite. Safe in shops, restaurants, convenience stores. Use while pointing.

## Variations

1. これください。 (kore kudasai) — this one (near me)
2. それください。 (sore kudasai) — that one (near you)
3. あれください。 (are kudasai) — that one over there

## Practice summary

Observed, broken down, pronounced, recalled, transformed (kore/sore/are), and used in situation.

## Proof of capability (completed)

User demonstrated:

- Correct recognition and meaning of これください (kore kudasai)
- Clear understanding of distance differences (kore / sore / are)
- Accurate production without looking
- Correct transformation according to distance
- Appropriate use in a convenience-store situation
- Ability to repair a wrong choice using gestures + correct demonstrative

## Before

Could not ask for an object in Japanese in a simple, natural way.

## After

Can point to something and say これください。 (kore kudasai). Can switch to それ (sore) or あれ (are) according to distance. Can also correct a wrong selection using the same pattern + gestures.
