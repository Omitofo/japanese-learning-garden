# S004 — I’m Learning Japanese

## Seed

basic-repair (extension) / survival self-introduction

## Circumstance

You are in a real interaction and want to quickly explain that you are not a fluent speaker so the other person can adjust.

## Communicative objective

Be able to politely say that you are learning Japanese.

## Core phrase

すみません、日本語を勉強しています。 (sumimasen, nihongo o benkyou shiteimasu)

## Meaning

Sorry, I’m studying Japanese. / Excuse me, I’m learning Japanese.

## Breakdown

### Vocabulary

- すみません (sumimasen) — excuse me / sorry
- 日本語 (nihongo) — Japanese language
- を (o) — object particle
- 勉強しています (benkyou shiteimasu) — am studying / am learning

### Pronunciation

- 日本語 (ni-hon-go)
- 勉強しています (ben-kyou shi-te i-ma-su)

Smooth unit: **sumimasen, nihongo o benkyou shiteimasu**

## Variations

1. すみません、日本語を勉強しています。 (sumimasen, nihongo o benkyou shiteimasu)
2. 日本語を勉強しています。 (nihongo o benkyou shiteimasu)
3. 日本語がわかりません。 (nihongo ga wakarimasen)
