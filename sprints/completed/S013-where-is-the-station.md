# S013 — Where Is the Station?

## Seed

ask-where-something-is (extension with concrete noun)

## Circumstance

You need to find the train station or subway station. You want a simple, polite way to ask where it is.

## Communicative objective

Be able to ask where the station is using a concrete noun.

## Core phrase

駅はどこですか。 (eki wa doko desu ka)

## Meaning

Where is the station?

## Breakdown

### Vocabulary

- 駅 (eki) — station (train / subway)
- は (wa) — topic particle
- どこ (doko) — where
- です (desu) — polite copula
- か (ka) — question particle

### Structure

駅 + は + どこ + です + か。

Exactly the same frame as トイレはどこですか. Only the concrete noun changes.

### Pronunciation

- 駅 (e-ki)

Smooth unit: **eki wa doko desu ka**

### Context

Extremely useful when arriving in a new area, getting off a bus, or looking for the nearest station. Polite and clear. One of the highest-value location questions for travel in Japan.

## Variations

1. 駅はどこですか。 (eki wa doko desu ka) — standard version (recommended)
2. すみません、駅はどこですか。 (sumimasen, eki wa doko desu ka) — with polite attention-getter

## Practice summary

Observed, broken down, pronounced, recalled, varied (standard / with sumimasen), used in situation, and chained with attention + thanks.
