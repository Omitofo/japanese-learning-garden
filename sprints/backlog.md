# Backlog

Possible future capabilities. Not a mandatory syllabus. Order can change at any time.

## High value (Phase 0 focus)

- Ask for something (basic request)
- Say I don't understand
- Ask someone to repeat / speak more slowly
- Ask what something is
- Ask where something is
- Say what I want

## Later

- Talk about the past
- Talk about plans
- Describe experiences
- Describe an object or person
- Respond to simple questions
- Repair a misunderstanding more flexibly

---

The system chooses the next sprint based on current state, weaknesses, reuse potential, and communicative value — not by walking this list in order.
