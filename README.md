# Japanese Learning Garden

A personal, adaptive system for learning Japanese through small sprints focused on real communicative capability.

## What this is

This is **not** a traditional course, syllabus, or vocabulary list collection.

It is a garden of communicative seeds.

Each **sprint** plants or strengthens one small capability:

> What can I do in Japanese after this sprint that I could not do (or could not do as well) before?

## Core concepts

- **Seed** — A concrete communicative capability (e.g. "ask for something", "say I don't understand").
- **Sprint** — A small learning unit centered on one useful phrase inside a real situation.
- **Harvest** — The actual capability you gain.
- **Romanization** — Every Japanese word or phrase (kanji, hiragana, or katakana) must appear with its romanization next to it so you can connect sound and writing.

## How to use

1. Check `CURRENT_STATE.md` to see where you are.
2. Run a command from `commands/` (start with `01-next-sprint.md`).
3. Practice the sprint.
4. Log it and update the state.

The system decides structure. You focus on using Japanese.

## Key files

| File | Purpose |
|------|---------|
| `CURRENT_STATE.md` | Living snapshot of what you can do |
| `sprints/backlog.md` | Possible future capabilities |
| `logs/sprint-log.md` | Quick history of completed sprints |
| `system/` | Philosophy, principles, and frameworks |
| `commands/` | Instructions the AI follows when you ask for a command |

## Principle

> Learn only what increases communication.
> Every sprint must produce a capability.
> Reuse before adding.
> Keep the garden simple.
