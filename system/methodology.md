# Methodology

## Sprint flow

```
Circumstance
     ↓
Communicative objective
     ↓
Seed
     ↓
One core phrase (+ romanization)
     ↓
Breakdown
     ↓
Repetition
     ↓
Variations
     ↓
Use
     ↓
Proof of capability
     ↓
Harvest (Before → After)
```

## Selection priority for next sprint

```
Reuse
  >
Strengthen a weakness
  >
Extend an existing capability
  >
Create a new capability
```

This priority is not absolute. High-value real needs can introduce a new seed.

## Romanization in practice

Whenever Japanese appears:

- Write the Japanese script
- Immediately add romanization in parentheses or nearby

Example formats:

- これください。 (kore kudasai)
- これ (kore) + ください (kudasai)

Never leave Japanese without its sound representation.
