# Non-negotiable Principles

## 5.1 Communication first

Every decision must be justified by its contribution to communication.

> Learn only what increases communication.

## 5.2 Every sprint produces an increment

Never create a sprint whose only result is "I learned this rule."

There must be a resulting capability.

## 5.3 One communicative result per sprint

By default: **one seed/capability + one core phrase**.

## 5.4 One phrase can generate a lot of knowledge

A deep single phrase is better than many shallow ones.

## 5.5 Reuse before adding

Before introducing new knowledge, check whether existing knowledge can be reused.

> Reuse before adding.

## 5.6 Repetition is part of learning

New information should be expensive. Reuse should be cheap.

## 5.7 Situations have priority over lists

Think in real circumstances, not abstract categories.

## 5.8 No mastery barrier

A seed does not need to be 100% mastered to continue.

## 5.9 No obligatory calendar

There are no system deadlines or fixed 12-week schedules.

## 5.10 Tests on demand

Tests are tools to check capability, not separate subjects.

## 5.11 Keep the system simple

> Do not over-engineer the garden.

## Romanization (added requirement)

**Always** place romanization next to every Japanese word or phrase (kanji, hiragana, or katakana).

This is mandatory in every sprint, explanation, variation, and test.
