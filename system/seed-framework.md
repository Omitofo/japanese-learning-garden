# Seed Framework

A **seed** is a communicative capability, not a grammar point or vocabulary category.

## Status values

- `new` — not really worked on yet
- `growing` — initial capability exists, needs more watering
- `usable` — can be used reasonably in a known situation

A seed can return to `growing` if weakness appears. That is normal.

## Levels / Zones

Levels only organize complexity. They are **not** prerequisites or locked gates.

Example zones:

- L00 — Survival
- L01 — Basic action
- L02 — Description
- L03 — Interaction
- L04 — Time and experience
- L05 — Plans and future
- L06 — Conversation
- L07+ — More complex communication

A learner can work on any zone at any time.
