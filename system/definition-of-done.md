# Definition of Done

A sprint is finished when:

- There is a clear communicative capability
- There is one core phrase (with romanization)
- The phrase has been understood
- Important elements have been explained
- It has been practiced
- The learner has tried to produce it without looking
- There is at least one useful variation or transfer when appropriate
- There is a proof of capability
- Before → After can be described

**Done means usable, not perfect.**

No requirement for 100% memorization or full related grammar mastery.
