# Sprint Framework

A sprint is the basic unit of learning.

## Required elements

- Circumstance (real-life situation)
- Communicative objective / Seed
- One core phrase (with romanization)
- Meaning
- Breakdown (vocabulary, structure, necessary grammar, particles, pronunciation)
- Context of use
- A few useful variations (each with romanization)
- Practice path (observe → produce)
- Proof of capability
- Before → After
- Status (new / growing / usable)

## Size rule

Keep it small. One clear communicative gain.

## Romanization

Every Japanese item must include romanization.

## Definition of done

A sprint is done when the capability is **usable**, not perfect.
