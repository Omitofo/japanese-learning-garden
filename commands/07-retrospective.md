# Command 07 — Retrospective

Improve the system itself.

Examine:

- Do sprints produce real capabilities?
- Are they small enough?
- Is too much new information introduced?
- Is reuse happening enough?
- Are the phrases useful?
- Do the tests actually measure capability?
- Is complexity accumulating?
- Is there a better way to select seeds?

The retrospective may propose changes to system rules when there is clear evidence.
