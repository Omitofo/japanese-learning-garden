# Command 01 — Next Sprint

**Purpose:** Generate the next optimal sprint.

## Before generating

Read:

- `README.md`
- `CURRENT_STATE.md`
- `system/philosophy.md`
- `system/principles.md`
- `system/methodology.md`
- `system/sprint-framework.md`
- `system/definition-of-done.md`
- `system/seed-framework.md`
- `sprints/backlog.md`
- `logs/sprint-log.md`
- `logs/mistakes.md`
- `logs/observations.md`
- `logs/open-questions.md`

## Then

1. Evaluate current state
2. Identify a communicative need
3. Choose an existing seed or create a new one
4. Choose a circumstance
5. Choose **one** core phrase
6. Design the sprint (keep it small)
7. Break the phrase down
8. Create practice
9. Create a proof of capability
10. Define expected Before → After
11. Create the sprint file under `sprints/active/` (or directly under completed when finished)

## Mandatory

- Every Japanese word/phrase must include romanization.
- One communicative capability only.
- Prefer reuse over adding new material.
