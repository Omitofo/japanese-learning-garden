# Seed: basic-request

**Zone:** L00 — Survival  
**Status:** growing

## Capability

Be able to ask for an object in a simple way by pointing and using a demonstrative + ください (kudasai), and also with high-value concrete nouns.

## Core patterns learned

これください。 (kore kudasai)  
それください。 (sore kudasai)  
あれください。 (are kudasai)  
水をください。 (mizu o kudasai)  
お水をください。 (o-mizu o kudasai)  
お会計をください。 (o-kaikei o kudasai)  
お会計お願いします。 (o-kaikei onegaishimasu)

- Successfully extended in S010 with 水 / お水.
- Successfully extended in S011 with お会計.
