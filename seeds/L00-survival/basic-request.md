# Seed: basic-request

**Zone:** L00 — Survival  
**Status:** growing

## Capability

Be able to ask for an object in a simple way by pointing and using a demonstrative + ください (kudasai), with high-value concrete nouns, and with quantities.

## Core patterns learned

これください。 (kore kudasai)  
それください。 (sore kudasai)  
あれください。 (are kudasai)  
水をください。 (mizu o kudasai)  
お水をください。 (o-mizu o kudasai)  
お会計をください。 (o-kaikei o kudasai)  
お会計お願いします。 (o-kaikei onegaishimasu)  
一つください。 (hitotsu kudasai)  
二つください。 (futatsu kudasai)  
水を一つください。 (mizu o hitotsu kudasai)
