# Seed: ask-where-something-is

**Zone:** L00 / early interaction  
**Status:** growing

## Capability

Be able to ask where something is while pointing, using the three distance demonstratives.

## Core patterns learned

これはどこですか。 (kore wa doko desu ka)  
それはどこですか。 (sore wa doko desu ka)  
あれはどこですか。 (are wa doko desu ka)
